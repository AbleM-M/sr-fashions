# SR Fashions website

A simple static website: plain HTML and CSS, no build step.

## Files
- `index.html`: home page (header, about, contact, image previews)
- `gallery.html`: full gallery page
- `style.css`: all the styling
- `script.js`: the small scroll animation
- `images/`: logo and photos

## To do before publishing
1. Save your logo as `images/logo.png`.
2. In `index.html`, replace the two `YOUR-...-LINK` placeholders (WhatsApp group and enquiry form).
3. Rewrite the About text.
4. Replace the `sample-*.svg` placeholders with real photos (update the file names in both HTML files).

## Preview locally
In VS Code, install the **Live Server** extension, right-click `index.html` and choose "Open with Live Server".

## Publish (GitHub Pages)
Push to GitHub, then go to Settings > Pages and choose the `main` branch and `/ (root)`.
